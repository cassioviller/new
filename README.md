# new

This repository contains the initial setup for a SaaS accounting management project.

## Getting Started

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```

2. **Enter the project directory**:
   ```bash
   cd new
   ```

3. **(Optional) Create a virtual environment** with Python 3.11:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. **Install dependencies** once a `requirements.txt` is added:
   ```bash
   pip install -r requirements.txt
   ```

5. **Start developing** your application.

This repository currently only contains this README. Additional code will be added as the project evolves.

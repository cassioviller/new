# new

This repository contains the initial setup for a SaaS accounting management project.

## Setup

Follow these steps to prepare a development environment with **Python 3.11**.

1. **Clone the repository** and enter it:
   ```bash
   git clone <repository-url>
   cd new
   ```

2. **Create a virtual environment** (optional but recommended):
   ```bash
   python3.11 -m venv .venv
   source .venv/bin/activate
   ```

3. **Install the dependencies** listed in `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
   The current file contains a minimal placeholder list that will grow as the project evolves.

4. **Run tests** (once test files are available):
   ```bash
   pytest
   ```

5. **Start developing** your application.

This repository currently only contains this README and a placeholder `requirements.txt`. Additional code will be added as the project evolves.
